# ZG-20 钳形万用表使用手册

ZG-20 是一款交流钳形万用表。除了万用表的常规功能，它可以用钳口直接夹住导线测量交流电流，不需要断开电路，适合空调、电机、配电箱等大电流场合的检修。

## 安全须知

- 钳口只能测量带绝缘层的单根导线，不要夹裸露的导体。
- 被测导线的对地电压不得超过 600V。
- 测量电流时请把表笔从插孔上取下，避免表笔误触带电部位。
- 钳口有裂纹或闭合不严时请停止使用。
- 不要在雷雨天气进行户外测量。

## 用钳口测量交流电流

1. 把旋钮转到交流电流档（A～），不确定电流大小时先选 400A 量程。
2. 按下扳机张开钳口，夹住一根导线，松开扳机让钳口完全闭合。
3. 让导线尽量位于钳口中央，读取屏幕上的数值。
4. 读数不方便观察时，按 HOLD 键锁定读数后再取下钳表。

一次只能夹一根导线。同时夹住火线和零线时两者的磁场相互抵消，读数接近 0，这不是故障。ZG-20 的钳口只能测量交流电流，不能测量直流电流。

交流电流有 4A、40A、400A 三个量程，钳口最大张开 28mm。测量小于 1A 的电流时，可以把导线在钳口上多绕几圈，读数除以圈数就是实际电流。

## 测量电压

1. 黑表笔插入 COM 插孔，红表笔插入 VΩ 插孔。
2. 把旋钮转到交流电压档（V～）或直流电压档（V⎓）。
3. 两支表笔接触被测的两点，读取数值。

ZG-20 的电压档为自动量程，最高可测 600V，不需要手动选择量程。

## 测量电阻、通断和电容

- 电阻：旋钮转到 Ω 档，表笔接在被测元件两端。测量前必须断电。
- 通断：旋钮转到蜂鸣档，阻值低于 30Ω 时蜂鸣器鸣响。
- 电容：旋钮转到电容档（符号为 ⊣⊢），测量前先给电容放电，大电容需要等待数秒读数才会稳定。

## 非接触验电（NCV）

把旋钮转到 NCV 档，将钳头顶端靠近插座或导线。检测到交流电压时指示灯闪烁并伴有蜂鸣声，信号越强闪烁越快。NCV 只用于初步判断是否带电，没有报警不代表一定没电，接触导体前仍需用表笔确认。

## 更换电池

屏幕出现电池符号时需要更换电池。

1. 把旋钮转到 OFF，取下表笔，并把钳表从导线上取下。
2. 拧开背面电池盖的螺丝，取下电池盖。
3. 取出旧电池，按正负极方向装入两节新的 7 号（AAA）1.5V 电池。
4. 装回电池盖并拧紧螺丝。

请不要新旧电池混用。长期不用时请取出电池。

## 常见问题

| 现象 | 可能的原因 | 处理方法 |
| --- | --- | --- |
| 夹住导线读数为 0 | 同时夹住了火线和零线，或导线中没有电流 | 只夹一根导线 |
| 电流读数偏小 | 钳口没有完全闭合，或导线偏离中心 | 清洁钳口接合面，重新夹持 |
| NCV 没有反应 | 导线带屏蔽层，或距离过远 | 靠近导线，改用表笔测量确认 |
| 自动关机太快 | 开启了省电模式 | 开机时按住 HOLD 键可关闭自动关机 |

## 技术参数

| 项目 | 参数 |
| --- | --- |
| 显示 | 3¾ 位液晶屏，最大显示 3999 |
| 交流电流 | 4A / 40A / 400A，精度 ±(2.0%+8) |
| 交流电压 | 自动量程，最高 600V，精度 ±(1.0%+5) |
| 直流电压 | 自动量程，最高 600V，精度 ±(0.8%+3) |
| 电阻 | 自动量程，最高 40MΩ |
| 电容 | 自动量程，最高 4000μF |
| 钳口张开尺寸 | 28 mm |
| 电源 | 7 号（AAA）1.5V 电池两节 |
| 自动关机 | 无操作 10 分钟后自动关机 |
| 尺寸与重量 | 200 × 68 × 35 mm，约 210 g（含电池） |

## 保修

整机自购买之日起保修一年。表笔和电池属于耗材，不在保修范围内。钳口因夹持超大导线造成的变形不予保修。
