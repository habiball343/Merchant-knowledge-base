# ZG-12 数字万用表使用手册

ZG-12 是一款手持式 3½ 位数字万用表，可测量交直流电压、直流电流、电阻、通断和二极管，适合家庭电工、电子爱好者和设备维护人员使用。使用前请完整阅读本手册，并妥善保存以备查阅。

## 安全须知

- 测量前检查表笔绝缘层是否完好，如有破损或金属外露请立即更换表笔。
- 不要测量高于 600V 的电压，否则可能损坏仪表并危及人身安全。
- 测量高于 36V 的直流电压或 25V 的交流电压时，手指不要越过表笔的护指环。
- 切换档位前，必须先把表笔从被测电路上取下。
- 不要在潮湿、有易燃气体或强磁场的环境中使用仪表。
- 屏幕出现电池符号时请及时更换电池，电量不足会导致读数偏差。

## 面板说明

仪表正面从上到下依次是液晶显示屏、功能按键、档位旋钮和表笔插孔。

| 部件 | 说明 |
| --- | --- |
| 显示屏 | 最大显示 1999，带背光和单位符号 |
| HOLD 键 | 按一下锁定当前读数，再按一下解除 |
| 背光键 | 长按 2 秒开启或关闭背光，背光 30 秒后自动熄灭 |
| 档位旋钮 | 选择测量功能和量程，OFF 位置为关机 |
| COM 插孔 | 黑表笔插孔，所有测量共用 |
| VΩ 插孔 | 红表笔插孔，用于电压、电阻、通断和二极管测量 |
| mA 插孔 | 红表笔插孔，用于 200mA 以内的电流测量 |
| 10A 插孔 | 红表笔插孔，用于 200mA 到 10A 的电流测量 |

## 测量直流电压

1. 黑表笔插入 COM 插孔，红表笔插入 VΩ 插孔。
2. 把旋钮转到直流电压档（V⎓）。不确定被测电压大小时，先选最高量程 600V，再逐级降低。
3. 红表笔接被测电路的正极，黑表笔接负极，读取屏幕上的数值。
4. 屏幕显示负号，说明表笔接反了，读数的绝对值仍然有效。
5. 屏幕只显示 OL，说明被测电压超出了当前量程，请换用更高的量程。

直流电压共有 200mV、2V、20V、200V、600V 五个量程。测量 5 号、7 号干电池时使用 2V 量程，测量 9V 电池和 12V 蓄电池时使用 20V 量程。

## 测量交流电压

1. 黑表笔插入 COM 插孔，红表笔插入 VΩ 插孔。
2. 把旋钮转到交流电压档（V～），家用插座请选择 600V 量程。
3. 两支表笔分别接触被测的两点，不分正负，读取屏幕上的数值。

交流电压有 200V 和 600V 两个量程。测量市电时请单手操作，不要同时用双手接触两支表笔的金属部分。

## 测量电阻与通断

测量电阻前必须断开被测电路的电源，并给电容放电，带电测量会损坏仪表。

1. 黑表笔插入 COM 插孔，红表笔插入 VΩ 插孔。
2. 把旋钮转到电阻档（Ω），选择合适的量程。
3. 两支表笔接在被测电阻两端，读取数值。显示 OL 表示阻值超出量程或电路断开。

通断测量请把旋钮转到蜂鸣档。两点之间的电阻低于 50Ω 时蜂鸣器持续鸣响，表示线路导通；没有声音并显示 OL 表示线路断开。

## 测量直流电流

电流测量需要把仪表串联进电路。

1. 先断开被测电路的电源。
2. 黑表笔插入 COM 插孔。电流小于 200mA 时红表笔插入 mA 插孔，更大的电流插入 10A 插孔。
3. 把旋钮转到对应的直流电流量程，把两支表笔串联在断开的电路中。
4. 接通电源，读取数值。

使用 10A 量程时，单次测量不要超过 10 秒，两次测量之间至少间隔 15 分钟。严禁在电流档把表笔并联到电源两端，这会烧断保险丝。

## 更换电池和保险丝

屏幕左上角出现电池符号时需要更换电池。

1. 把旋钮转到 OFF，取下两支表笔。
2. 用十字螺丝刀拧开背面电池盖上的一颗螺丝，取下电池盖。
3. 取出旧电池，按电池仓内标示的正负极方向装入一节新的 9V 6F22 电池。
4. 装回电池盖并拧紧螺丝。

mA 插孔使用 250mA/250V 的快熔保险丝，10A 插孔使用 10A/250V 的快熔保险丝。更换保险丝需要拧开后壳的四颗螺丝，请使用相同规格的保险丝，不要用铜丝代替。

## 常见问题

| 现象 | 可能的原因 | 处理方法 |
| --- | --- | --- |
| 开机没有显示 | 电池没电或装反 | 更换电池，检查正负极方向 |
| 读数不停跳动 | 表笔接触不良，或附近有强电磁干扰 | 清洁表笔尖端，远离变频器和电机 |
| 电流档始终显示 0 | 保险丝熔断 | 更换相同规格的保险丝 |
| 测电阻时显示 OL | 量程太小，或电路断开 | 换更高量程，检查接线 |
| 屏幕字迹变淡 | 电池电量不足 | 更换电池 |

## 保修

整机自购买之日起保修一年。表笔、电池、保险丝属于耗材，不在保修范围内。因摔落、进水、超量程使用或私自拆修造成的损坏不予保修。申请保修时请提供购买凭证。
